# SUDOKU LEGEND V2.7

기존 V2.6 프로젝트의 게임 엔진, RPG, 일일 도전, 설정, 로컬 저장 키를 유지하면서 화면 배치만 개선했습니다.

- PC 화면 높이에 맞춰 스도쿠 게임판 크기를 자동 조절합니다.
- 상단의 🎯 집중 모드 버튼으로 좌우 패널을 숨기거나 복원합니다.
- 골드 및 라이트 테마의 일부 네이비 버튼/패널 색상을 정리했습니다.
- 브라우저 F11 전체 화면은 브라우저 자체 기능을 이용합니다.
- 모바일에서는 화면 너비를 기준으로 게임판을 배치합니다.

## 설치
압축 파일을 풀어 나온 내용물을 `D:\00.Projects\Sudoku_Legend\`에 덮어쓴 뒤 `index.html`을 열고 Ctrl+F5를 누르세요.

## 주의
작은 모니터에서 게임판은 가독성을 위해 최소 크기를 유지하므로, 화면 높이가 매우 낮거나 브라우저 확대 배율이 높으면 스크롤이 필요할 수 있습니다. PC와 스마트폰의 저장 데이터 동기화는 아직 구현되지 않았습니다.

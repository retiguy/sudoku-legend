SUDOKU LEGEND APK starter
Upload the CONTENTS of this ZIP to the root of the existing GitHub repository, preserving folders.
GitHub > Actions > Build Sudoku APK > Run workflow.
Download artifact SudokuLegend-debug-apk, unzip, install app-debug.apk.
